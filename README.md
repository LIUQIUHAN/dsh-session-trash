# 会话回收站

> 删除会话不再是一次性的操作 —— 先进回收站，随时可以找回来。

DSH 原本没有删除会话的入口，想清理只能手动去翻目录。这个插件把「删除」做成两步：**移入回收站** 随时可还原，**彻底清除** 才真正删掉，并且顺手补上了对话预览、同名防误删和到期自动清理。

所有操作都在本机完成，不联网、不上传任何会话内容。

## 主要能力

| 能力 | 说明 |
| --- | --- |
| 移入回收站 | 会话行「⋯」菜单里多一项，整个会话目录移走而不是删除 |
| 一键恢复 | 回收站里点「恢复」，目录与会话登记一起还原 |
| 彻底清除 | 二次确认后永久删除，无法恢复 |
| 对话预览 | 删除前在确认弹窗、删除后在面板里都能看首条指令与最后回复 |
| 同名防误删 | 同名会话会在确认弹窗里并列对照，避免删错 |
| 定期自动清理 | 可设置保留天数与检查间隔，到期自动彻底删除 |
| 活跃会话保护 | 有未完成步骤的会话拒绝删除，避免截断 |

## 怎么用

1. 鼠标移到侧边栏的会话行，点「⋯」，选择 **移入回收站**
2. 在确认弹窗里核对完整 `sessionId` 和首条用户指令，确认删除
3. 点侧边栏底部的 **回收站** 打开面板
4. 面板里可以：**恢复** / **查看对话** / **彻底清除**

## 回收站面板

- **顶部**：自动清空开关、保留天数、保存设置、清空回收站
- **列表**：会话标题、剩余天数（3 天内转为黄色，过期转为红色）、删除时间、体积、完整 `sessionId`
- 每张卡片都有「恢复」「查看对话」「彻底清除」三个操作
- 「彻底清除」和「清空回收站」都需要**再点一次确认**，防止误触

## 数据放在哪

```
~/.dsh/
├── .session-cleaner-trash/          # 回收站
│   └── <sessionId>/
│       ├── .trash-info.json         # 删除时间、标题、原工作区等元数据
│       └── session-data/            # 原会话目录（日志原样保留）
└── session-cleaner-settings.json    # 自动清空设置（独立文件，不会被清理）
```

卸载插件不会删除上面这些数据，重新安装后回收站内容仍在。

## 边界与注意

- **自动清空默认开启**：回收站内条目满 30 天后会被永久删除，可在面板里调整天数或直接关闭
- 恢复后会话会重新登记进工作区，**刷新界面**（`F5` 或面板里的「刷新」）即可看到，不需要重启 DSH
- 会话目录不存在时无法删除；有未完成步骤的会话会被拒绝
- 界面选择器依赖 DSH 的 DOM 结构，DSH 大版本更新后可能需要重新适配

## 与第三方侧边栏的兼容

`dsh-better-workspace` 这类插件会自绘会话行，不再复用 DSH 官方的 `_menuOpen` 类名，行上也只带 `sessionId` 而不是 `session.id`。本版本针对这种情况做了适配：

- 会话行的定位不再只依赖官方类名，改为同时识别 `.bw-row.menu-open`，并记录右键命中的元素反查所属行（`[data-row-key]` / `.bw-session-row`）
- `sessionId` 支持从 `p.sessionId` 读取，官方结构仍优先

如果你同时用着多个接管侧边栏的插件而菜单项仍不出现，多半是那套 DOM 结构又变了，可以提 issue 附上会话行的 HTML 片段。

## 安装

```bash
dsh plugin add @dsh2030/session-trash
```

或在 DSH 的「插件」页面点「添加插件」，填入包名 `@dsh2030/session-trash`。

> 注意：npm 上另有一个 `dsh-session-trash`（0.1.x，作者不同、实现不同），本包与之没有代码关系，故使用独立作用域发布。
